CARLOATHLETES — FRONTEND DEMO

HOW TO OPEN
1. Extract CarloAthletes.zip.
2. Open the CarloAthletes folder.
3. Double-click index.html to open it in Chrome.

FEATURES
- Dark responsive esports landing page.
- Demo signup/sign-in stored only in this browser using localStorage.
- Player profile fields: display name, Free Fire IGN, UID and optional team.
- BR details: 50-player capacity, squad format, 4:25 PM room details, 4:30 PM match.
- CS details: 4v4.
- Instagram contact link: https://www.instagram.com/i.yuvi.o76/
- My Org / Szn1.esp! section.
- Scroll reveal animations.

IMPORTANT LIMITATIONS
This is a frontend prototype, not a production tournament system.
The demo login is NOT secure authentication and passwords are stored locally in this browser. Do not use a real or reused password.
There is no real database, admin dashboard, room assignment, payment system, or automatic registration.
The Instagram button opens the organizer profile; it does not confirm a match slot.
For real public deployment, connect a secure authentication provider and database, then test permissions and privacy rules.
